Project Scope and ToDos

  1. Log in to ATProto
  2. Post archives to a PDS.
  • Remember my login.
  • List records
  • Upload a warcz or warc blob
  • List records with links to uploaded blobs.

Day 3

This is a start, but I need to set up the property for the uploaded archive file. That means I'll need the mime-type. For WARC files it will be application/warc. For the compressed files it looks like the right value is application/wacz.

I'll also need to set a maximum file size that respects the PDS maximum file size. That is 50mb. That's pretty small. I may want to set up a way to have a session associated in a series of files, that would be another lexicon though. Let's go one at a time. I'll add the property:

Skip code block ▼

"archiveFile": {
	"accept": [
		"application/warc",
		"application/wacz"
	],
	"description": "Blob that stores the warc or wacz archive on your PDS. Less than 50MB in size.",
	"maxSize": 52428800,
	"type": "blob"
},

Looking around, it looks like people also store files at warc.gz.

So I'll add the application/warc+gzip mime type.

git commit -am "Adding archiving session lexicon and the document.standard.site lexicon for reference"

Ok, I've got a basic record. Let's try publishing:

goat account login -u chronotope.aramzs.xyz -p <app password here>

Now I can upload a basic blob from Markpub.at as an archive as a file:

goat blob upload ./static/markpubat.wacz

That gives me back an ID:
